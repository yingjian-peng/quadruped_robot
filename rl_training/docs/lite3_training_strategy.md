# Lite3 训练与优化策略

本文记录 Lite3 当前训练配置的设计依据、首轮训练顺序和后续优化边界。目标不是一次性堆叠更多
reward，而是建立可重复评测、可逐项归因、最终可在真机验证的运动控制策略。

## 一、当前策略接口

控制周期为 50 Hz。策略输出 12 维关节位置目标增量：

```text
q_target = q_default + action_scale × policy_action
```

- `HipX` action scale：0.125 rad。
- `HipY` 与 `Knee` action scale：0.25 rad。
- Lite3 资产已切回官网参考：`HipX=0`、`HipY=-0.65`、`Knee=1.30` rad；机身初始高度为 0.375 m。
- 执行器采用官网 `DelayedPDActuatorCfg`：`kp=30`、`kd=1`、0–1 步延迟，Hip/Knee 力矩限制 24/36 N·m。当前部署 runner 仍为 `kd=0.5` 和 `HipY/Knee=-0.67/1.34`，后续需通过硬件参数核实与对照评测决定是否同步；不可把旧 checkpoint 视为新配置的验证。
- 控制频率 50 Hz，命令范围 `v_x/v_y/ω_z = ±1`，与 runner 的 `max_cmd_vel_` 一致。

## 二、观测设计

actor 使用真机可获得的信息：

- base 角速度与 projected gravity；
- `[v_x, v_y, ω_z]` 速度命令；
- 12 维关节位置与关节速度；
- 上一帧 12 维动作；
- 0.6 s 周期的 `sin/cos` 步态相位。

actor 不使用 base 线速度，避免部署时依赖难以稳定估计的输入。critic 可额外使用仿真中的 base
线速度，以提高训练效率但不扩大部署接口。平地任务不配置地形高度扫描。

步态相位在零命令时置零。相位观测与接触时钟 reward 必须使用相同周期，否则会向策略提供互相
矛盾的信号。

## 三、命令分布与课程

训练直接使用 yaw-rate 命令，不通过 heading 控制器间接生成转向。非站立环境按以下比例采样：

| 命令族 | 比例 | 约束 |
| --- | ---: | --- |
| 前后 | 25% | 仅 `v_x` 非零 |
| 横移 | 25% | 仅 `v_y` 非零 |
| 原地转向 | 25% | 仅 `ω_z` 非零 |
| 混合 | 25% | 三轴均可非零 |

这样可以避免独立均匀采样几乎从不产生纯横移或纯转向的问题。

线速度和角速度课程从完整范围的 20% 开始。当对应跟踪 reward 的 episode 均值达到最大值的 80%
后，每次将上下界各扩展 0.1，直到完整的 `[-1, 1]` 范围。

## 四、步态与运动质量约束

当前目标是对角小跑：`FL/HR` 同相，`FR/HL` 同相，两组相差半周期。四个足端以
`FL_FOOT, FR_FOOT, HL_FOOT, HR_FOOT` 的显式顺序绑定，不能依赖 USD 内部遍历顺序。

主要机制：

- `feet_gait=1.2` 使用 v3 的对角时钟奖励。
- `feet_contact_without_cmd=0.2`：零命令时鼓励足端接触。
- `feet_air_time=0.3`：腾空阈值为 `0.22 s`，与 `0.6 s` 周期和 56% 支撑占空比匹配。
- `feet_air_time_variance=-1.0`：抑制四足接触/腾空时间严重失衡。
- `feet_slide=-0.45`、`feet_stumble=-0.5`：抑制支撑脚滑移以及足端横向刮碰。
- `feet_height=-5.0`：平地训练中约束运动足世界高度接近 `0.08 m`，并关闭会影响支撑腿的 `feet_height_body`。
- `joint_mirror=-0.08`：加强 `FL/HR` 与 `FR/HL` 两组对角腿的关节协调。
- `base_height_l2=-12.0`：目标机身高度同步官网为 `0.55 m`；另用
  `base_height_below_target=-4.0` 惩罚低于 `0.32 m` 的持续下蹲。保留本工程的有效权重尺度，不照搬官网配置中的 `-50`。
- `joint_pos_penalty=-0.5`、`stand_still_scale=5.0`、`action_rate_l2=-0.04`：约束腿部动作幅度和相邻控制周期的动作突变。
- v3.1 的 `undesired_contacts=-3.0`：相对 v3 的 `-1.0`，只提高非足端承重的代价；先评估后小腿接触占空比是否下降。
- `track_lin_vel_y_exp=1.0`、`track_ang_vel_z_exp=2.25`：确保横移和转向不被前后运动样本淹没。

这些项是一个组合。若只增强时钟而不保证横移/转向样本覆盖，策略可能获得整齐直行步态但无法完成
遥控命令；若只增强横移而完全移除时钟，动作平滑度和步态一致性通常会恶化。

## 五、域随机化阶段

当前先运行窄随机化的平地基准阶段：

- reset x/y：±0.05 m，z：±0.02 m；roll/pitch：±0.05 rad，yaw：±π；初始线速度 ±0.05 m/s、角速度 ±0.05 rad/s（竖直速度 ±0.02 m/s）；
- 机身质量增量：±0.1 kg；其他刚体质量缩放：0.98～1.02；
- 质心偏移：各轴 ±0.005 m；
- 摩擦系数：静/动均为 0.95～1.0，恢复系数 0～0.02；
- reset 外力 ±1 N、外力矩 ±0.5 N·m；周期推扰速度 x/y ±0.1 m/s；
- stiffness、damping 缩放：0.95～1.05。

这个阶段先确认名义站姿和控制策略能稳定工作。站立、命令跟踪和接触指标达到门槛后，再逐组扩大质量/质心、执行器、地面和外力随机范围；每次扩大后保留固定名义条件评测。进入 Sim-to-Real 前，应使用真机质量、质心、关节摩擦、
控制延迟、电机响应和 IMU 噪声的实测范围替换经验区间，而不是无上限扩大随机化。

## 六、推荐实验顺序

1. **v3 基线**：已对现有 `model_4999.pt` 完成 5 trials、8 s、2 s warmup 的固定协议评测，数据见 [迭代记录](lite3_iteration_log.md)。
2. **先查站姿**：零动作与策略都出现后足不接触，先核对碰撞几何和默认姿态的落地过程；站立偏航漂移另查策略输出。
3. **再查运动高度**：历史 v3 运动时机身平均约 0.299 m；当前候选目标为 0.55 m，需用新训练验证目标可达性及对速度跟踪的影响。
4. **小步续训结果**：v3.1 只提高非足端接触惩罚，从 v3 `model_4999.pt` 追加 300 次迭代，并让新环境从完整速度命令范围开始。结果改善站立偏航，但没有形成稳定四足支撑，运动高度略降；详见 [迭代记录](lite3_iteration_log.md)。
5. **单变量或小组合消融**：每次只修改一个 reward 权重或一组强耦合参数。
6. **Sim-to-Sim**：核对关节顺序、默认角、动作 scale、控制频率和观测归一化。
7. **Sim-to-Real**：先悬空、再支架、最后落地；逐级提高动作幅度和速度范围。

2026-10-10 原先尝试将 USD 小腿碰撞切换为 `shank.STL` 凸包，但官网训练包中 USD 基础层与本工程原始 USD 内容不同。现已恢复官网 `Lite3_base.usd`，而不是继续沿用试验性碰撞改动。URDF 中 STL 是视觉模型、小腿碰撞体是两段圆柱；MJCF 使用 STL 网格碰撞，因此不同格式间仍有官方模型自身的表示差异。当前平地基准随机化已经收窄；模型与执行器恢复后，必须重新做名义站姿基准。

## 七、v3 基线与下一版门槛

v3 完整基线已记录，下一版至少对以下指标确定目标和退化上限：

- locomotion：`mae_vx`、`mae_vy`、`mae_wz`；
- stand：`actual_vx/vy/wz` 与关节功率；
- stability：`tilt_rad`、`vertical_acc_abs`、终止率；
- posture：`base_height_m`，与当前 `0.55 m` 目标比较，并确认提升高度时速度跟踪、关节力矩和跌倒率没有明显退化；
- contact：`stance_slip_mps` 与四足 duty factor，尤其是 v3 站立时后足接触占空比均为 0；
- smoothness：`action_rate_l2` 与 `joint_deviation_mean_abs_rad`；
- gait：`gait_clock_match`、对角腿同步和摆动相触地率。

门槛应基于多次 trial 的均值和方差，并以真机安全约束为最终依据。
