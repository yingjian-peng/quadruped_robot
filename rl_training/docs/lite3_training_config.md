# Lite3 平地训练配置说明

本文记录当前代码中 DeepRobotics Lite3 平地速度任务的配置，供以后逐项核对和修改。这里描述的是**当前源码配置**；训练 run 自带的 `params/env.yaml`、`params/agent.yaml` 才是对应 checkpoint 的历史快照。修改配置后，旧 checkpoint 不会自动变成新配置训练出来的结果。

## 2. 机器人资产、初始位姿和执行器

- 训练资产：`robot_models/deeprobotics/Lite3/Lite3_usd/Lite3.usd`，通过 `DEEPROBOTICS_LITE3_CFG` 加载，并启用接触传感器。
- 初始机身根位置：`(x,y,z)=(0,0,0.375) m`，姿态为单位四元数；初始根线速度和角速度为零。
- 12 个关节按 `FL, FR, HL, HR`、每腿 `HipX, HipY, Knee` 排列。默认角依次是 `(0,-0.65,1.30) rad`，关节初始速度为零。
- 软关节限位比例：`0.99`。
- HipX/HipY 执行器：延迟 PD，力矩上限 `24 N·m`、速度上限 `26.2 rad/s`、`kp=30`、`kd=1`、延迟 `0–1` 个仿真步。
- Knee 执行器：延迟 PD，力矩上限 `36 N·m`、速度上限 `17.3 rad/s`、`kp=30`、`kd=1`、延迟 `0–1` 个仿真步。
- USD 刚体求解器迭代数为位置 `4`、速度 `1`；自碰撞关闭，重力开启，线性和角阻尼为零。
- 部署 runner 的关节顺序与此一致，但其默认角和阻尼在源码中是 `HipY=-0.67`、`Knee=1.34 rad`、`kd=0.5`。因此资产的初始姿态和 PD 阻尼仍需与实际部署版本确认；不要仅凭训练配置文档推断 sim-to-real 已一致。

## 3. 仿真、地形和时序

- 地形为本地平面网格，尺寸 `512 × 512 m`，无高程变化。
- 物理步长 `dt=0.005 s`，控制 decimation 为 `4`，策略动作频率为 `50 Hz`。
- 单个 episode 为 `20 s`；默认环境数 `4096`，训练命令可用 `--num_envs` 覆盖。
- 地面静/动摩擦为 `1.0`，摩擦合并方式为乘法。机器人接触材质随机化会改变接触对的最终摩擦。
- 接触传感器以物理步长更新，记录 3 帧历史并跟踪腾空时间。

## 4. 策略输入与动作

### Actor 观测：47 维

按配置拼接顺序：

| 观测 | 维数 | 处理 |
| --- | ---: | --- |
| 机身角速度 | 3 | scale `0.25`，继承均匀噪声 `±0.2` |
| 机身坐标系投影重力 | 3 | scale `1.0`，继承噪声 `±0.05` |
| 速度命令 `(vx,vy,wz)` | 3 | 原值 |
| 关节位置相对默认角 | 12 | scale `1.0`，噪声 `±0.01` |
| 关节速度相对值 | 12 | scale `0.05`，继承噪声 `±1.5` |
| 上一时刻动作 | 12 | 原值 |
| trot 相位 `(sin,cos)` | 2 | 周期 `0.6 s`；站立命令时置零 |

Actor 不输入 base 线速度；Critic 输入额外包含 base 线速度 3 维，因此 Critic 为 50 维。Actor 和 Critic 都包含同一个 2 维相位信号。策略观测 corruption 开启，Critic corruption 关闭。

### 动作输出

- 12 维关节位置增量，使用默认关节角作为 offset，关节排列为 `FL, FR, HL, HR`，每腿 `HipX, HipY, Knee`。
- HipX 动作比例 `0.125`，其余关节 `0.25`；动作裁剪配置为 `[-100,100]`，实际归一化动作一般远小于该界限。
- 这组比例与当前部署 runner 的 action scale 相同；导出/部署时仍须核对 observation 顺序、相位输入和 `last_action` 初始化。

## 5. 命令和课程

- 直接使用 `(vx,vy,wz)` 命令，不使用 heading command；每 `10 s` 重采样。
- 速度范围最终为 `vx,vy,wz ∈ [-1,1]`；课程从最终范围的 `20%` 开始，线速度和偏航速度根据跟踪奖励逐渐扩展到 `100%`。
- 约 `2%` 环境采样站立命令。其余命令将前后、横移、原地转向、混合运动四种模式各分配 `25%`；当前纯前后和混合模式的负向 `vx` 采样概率均为 `0.50`，与 E 组一致。此前已分别测试全模式 `0.65` 和仅纯前后模式 `0.65`，后退误差下降，但支撑宽度、倾角或横移串动退化。
- trot 时钟的有效命令阈值为 `0.1`；站立时相位观测归零，步态奖励关闭。

## 6. 重置、域随机化和外力

当前是平地稳定策略阶段，随机范围刻意收窄；后续应基于稳定策略分阶段扩大并记录每次变更。

| 参数 | 当前范围 | 作用时机/说明 |
| --- | --- | --- |
| 根位置 x/y | `±0.05 m` | reset |
| 根高度 z | 初始值 `±0.02 m` | reset，围绕 `0.375 m` |
| 根 roll/pitch | `±0.05 rad` | reset |
| 根 yaw | `±3.14 rad` | reset，覆盖任意朝向 |
| 根线速度 x/y | `±0.05 m/s` | reset |
| 根线速度 z | `±0.02 m/s` | reset |
| 根角速度 roll/pitch/yaw | `±0.05 rad/s` | reset |

| TORSO 质量 | 标称质量加 `±0.1 kg` | startup |
| 其他刚体质量 | 标称质量的 `0.98–1.02` 倍 | startup |

## 7. 奖励与惩罚（当前版本）

奖励项由 `flat_env_cfg.py` 设置；调用公式和默认阈值在 `mdp/rewards.py` 及通用环境配置中。权重是每个控制步的缩放系数，不能脱离公式和运行日志中的各项 episode reward 单独判断影响大小。

### 速度跟踪和机身稳定

| 项目 | 权重/目标 | 用途 |
| --- | ---: | --- |
| 平面线速度跟踪 | `+3.0` | 跟踪 x/y 命令 |
| 横向速度跟踪 | `+1.0` | 对横移增加单独权重；与 xy 跟踪有意重叠 |
| 后退专用速度奖励 | `0`（已移除） | 曾试验 `+0.75`，后退 MAE 未改善且部分步态/姿态指标退化；当前不启用 |
| 偏航角速度跟踪 | `+2.25` | 跟踪 `wz` |
| 机身高度 L2 | `-20`，目标 `0.32 m` | 当前高度微调候选；资产出生根高仍为 `0.375 m`，两者用途不同 |
| 低于 `0.32 m` 的额外惩罚 | D基线 `-2`；E对照 `-4` | E组加权改善了支撑宽度与倾角，但高度未明显增加且速度跟踪退化；D/E保留作不同取舍 |
| 平地姿态惩罚 | `-5` | 惩罚机身倾斜 |
| 垂直机身速度 | `-2` | 抑制机身上下弹跳 |
| 水平机身角速度 | `-0.05` | 抑制 roll/pitch 角速度 |
| 机身线加速度 | `0` | 关闭 |
| 终止奖励项 | `0` | 跌倒由终止状态处理，不重复给此项惩罚 |

### 关节和动作平滑

| 项目 | 权重/参数 | 用途 |
| --- | ---: | --- |
| 关节力矩平方 | `-2.5e-5` | 保留主要用力代价 |
| 关节加速度平方 | `-2.5e-7` | 抑制关节加速度 |
| 关节位置限位 | `-5` | 接近/越过软限位时惩罚 |
| 关节位置偏差 | `-0.5`；站立放大系数 `3` | 站立时保持默认姿态，但相较旧系数 `5` 放松一些 |
| 关节镜像 | `-0.08`，仅 HipY/Knee | 沿用已评测的 nohipx 候选，保留对角腿 HipY/Knee 约束 |
| 动作变化率 | `-0.04` | 让连续策略动作更平滑 |
| 关节速度、速度限位 | `0` | 当前关闭 |
| 关节功率 | `0` | 关闭额外机械功率代价，当前基准保留力矩平方作为用力正则 |
| `stand_still` | `0` | 关闭；它与低命令下的关节位置偏差重复 |

### 足端接触和 trot 节拍

参考周期为 `0.6 s`，控制频率为 `50 Hz`，约每周期 30 个策略步。占空比阈值 `0.56`，对应名义支撑约 `0.336 s`、摆动约 `0.264 s`。相位偏置为 `[FL,FR,HL,HR]=[0,0.5,0.5,0]`，所以 FL/HR 同步、FR/HL 同步，两组相差半周期。相位每回合从 episode 时钟开始；运动时 actor 能看到 sin/cos 相位，站立命令下 actor 相位归零。

| 项目 | 权重/参数 | 用途 |
| --- | ---: | --- |
| 时钟接触匹配 `feet_gait` | `+1.5`，占空比 `0.56` | 逐足比较实际接触与 trot 时钟期望接触；四类运动命令均使用完整权重 |
| 足端腾空时间 | `+0.3`，阈值 `0.22 s` | 运动命令下，落足时按超过 `0.22 s` 的腾空时长给分；更短时长会形成负贡献 |
| 摆脚高度偏差 | `-2`，世界高度目标 `0.08 m` | 仅运动命令生效，按世界足端高度误差乘足端水平速度因子；已从 `-5` 减弱，避免它压过接触节拍 |
| 站立足端接触 | `+0.2` | 低命令时鼓励脚保持接触 |
| 小腿接触 | `-3`，力阈值 `1 N` | 处罚四条 SHANK 的非期望接触；不会仅因小腿接触而终止 episode |
| 足端接触力 | `-1.5e-4`，力阈值 `100 N` | 限制过大的足端冲击 |
| 足端绊碰 | `-0.5` | 处罚水平冲击明显大于垂直冲击的足端接触 |
| 足端滑动 | `-0.45` | 仅接触时按世界坐标水平足速处罚滑动 |
| 支撑脚横向宽度 | `-1`，四足统一 `0.13 m` | 当前阈值不变续训对照配置。前足 `0.145 m` 实验前进时改善前右足位置，但后足收窄、后退和起停退步；暂不采用，先与相同父 checkpoint 的阈值不变续训比较 |
| 足端腾空/支撑时间方差 | `0` | 关闭；由显式 per-foot trot 时钟处理接触节拍 |
| 通用 feet contact 项 | `0` | 关闭，避免与显式 gait 时钟重复约束接触数量 |
| body-frame 足高项 | `0` | 关闭，避免将支撑脚也约束到摆动高度 |
| `upward` | `0` | 关闭；其实现与函数说明不一致，而且与平地姿态项重复奖励直立姿态 |

这里的 `feet_gait` 奖励只检查接触是否符合时钟，没有强制每条腿的轨迹形状或足端速度。要判断“节拍是否规范”，应结合步态相位、接触占空比、四足落足时间和固定速度命令评测，而不能只看 PPO 总奖励。

## 8. 终止条件

- 根高度低于 `0.18 m`：判为跌倒并结束 episode。
- 姿态倾角超过 `0.8 rad`：判为跌倒并结束 episode。
- 通用 `illegal_contact` 终止项关闭，因此小腿触地通过 `undesired_contacts=-3` 惩罚，而不是触地即终止。
- episode 超过 `20 s` 时按 time-out 正常结束。

## 9. PPO 训练器

- 每个环境每次采样 `24` 步；`max_iterations=5000`；保存间隔 `100` 次。
- Actor/Critic MLP 均为 `[512,256,128]`，激活函数 ELU，初始动作噪声标准差 `1.0`。
- PPO：每轮 5 个 learning epochs、4 个 minibatches，clip `0.2`，value loss coef `1.0`，entropy coef `0.01`。
- 学习率 `5e-4`，adaptive schedule，目标 KL `0.01`；`gamma=0.99`、`lambda=0.95`、最大梯度范数 `1.0`。
- empirical normalization 关闭。

## 10. 修改和验证建议

1. 保存本次配置和训练 run 的 YAML 快照；训练时设置清楚的 `run_name`，不要把新奖励配置误认为旧 checkpoint 的配置。
2. 先跑配置创建/短时仿真 smoke test，确认 Actor/Critic 维度、奖励项和终止管理器加载成功。
3. 对候选策略固定评测站立、前进、后退、横移、原地转向和混合命令，观察机身高度、跌倒率、小腿承重、足端接触占空比、对角腿相位误差、速度跟踪误差。
4. 只有平地基准策略稳定后，再一次只扩大一组随机化范围，并保留对应 checkpoint、`env.yaml`、`agent.yaml` 和评测表。

训练参数的背景、历史 checkpoint 结论和配置变更记录分别见 [Lite3 迭代记录](lite3_iteration_log.md) 与 [训练策略说明](lite3_training_strategy.md)。
